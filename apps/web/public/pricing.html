Expert Advisor · MT5

Sync automatique en 3 minutes

Notre EA MT5 envoie vos trades à Zenith en temps réel, sans VPS, sans serveur. Il tourne sur votre propre MT5.

📦
ZenithBridge.ex5
📐 v2.1.0 ⚖️ 48 KB ✅ Compatible MT5 Build 4000+ 🔒 Signé & vérifié
1
Télécharger ZenithBridge.ex5
Cliquez sur le bouton ci-dessus. Votre clé API Zenith est générée automatiquement dans votre espace.
2
Ouvrir le dossier données MT5
Dans MT5 → Fichier → Ouvrir le dossier des données. Ou utilisez le raccourci :
Fichier → Ouvrir dossier données
3
Copier l'EA dans MQL5/Experts
Glissez ZenithBridge.ex5 dans le dossier :
MQL5 / Experts /
4
Rafraîchir le Navigateur MT5
Dans le panneau Navigateur → clic droit sur Expert Advisors → Actualiser. L'EA Zenith apparaît.
5
Glisser l'EA sur n'importe quel chart
Faites glisser ZenithBridge depuis le Navigateur sur un graphique ouvert (n'importe quel symbole, n'importe quelle période).
6
Entrer votre clé API Zenith
Une fenêtre de configuration s'ouvre. Collez votre API Key (copiez depuis Zenith → Paramètres → Intégrations).
Zenith → Paramètres → Intégrations → Copier la clé
7
Activer le trading algorithmique
Dans MT5 → barre d'outils → activez le bouton "Activer le trading algorithmique". L'icône EA dans le coin du chart doit être verte.
8
C'est tout. ✅
Vos trades suivants sont envoyés automatiquement à Zenith. L'historique passé est importable via CSV une seule fois.
✅ Trades synchronisés en temps réel
💡 Sans VPS L'EA tourne sur votre MT5 local. Aucun serveur externe requis. Les trades sont envoyés dès leur clôture tant que MT5 est ouvert.
🔒 Read-only L'EA est en lecture seule. Il envoie les données vers Zenith mais n'a aucun accès aux ordres ni à votre capital.
📁 Historique Pour importer vos trades passés, utilisez Fichier → Exporter historique dans MT5, puis importez le CSV dans Zenith.

FAQ

Questions fréquentes

L'EA MT5 est-il disponible sur Starter ?
Oui. L'EA est gratuit sur tous les plans. La différence : en Starter il envoie les trades mais la sync est manuelle (CSV). En Pro+, la sync est automatique en temps réel.
Ai-je besoin d'un VPS pour la sync auto ?
Non. L'EA tourne sur votre propre MT5. Tant que votre terminal est ouvert, vos trades arrivent sur Zenith en temps réel. Aucun serveur supplémentaire.
L'EA peut-il passer des ordres sur mon compte ?
Non. L'EA est en lecture seule. Il lit vos trades déjà exécutés et les envoie à Zenith. Il n'a aucun accès à votre capital ni à vos ordres.
Puis-je changer de plan à tout moment ?
Oui. Upgrade ou downgrade immédiat depuis votre espace. Aucun engagement. Le remboursement au prorata est calculé automatiquement.
Comment importer mon historique existant ?
Dans MT5 : Fichier → Rapport de compte → Exporter en CSV, puis importez dans Zenith. C'est une opération unique, après quoi l'EA prend le relais.
Compatible avec quels brokers ?
Tous les brokers qui proposent MetaTrader 5. L'EA utilise les API standard MT5, il n'est pas lié à un broker spécifique.
